# 🍽️ Ching Ling Restaurant

A modern and responsive website for Ching Ling Restaurant, designed to provide a smooth ordering experience for customers and efficient order management for the restaurant.

## 🚀 Features

- 📱 **Responsive design** – works on desktop, tablet, and mobile
- 🛒 **Digital menu with shopping cart** – customers can browse dishes, add items, and review their order
- 💬 **WhatsApp integration** – finalized orders are sent directly to the restaurant's WhatsApp, including delivery address and payment method
- 🌐 **Domain and hosting setup** – full configuration from scratch
- 🔍 **SEO optimization and Google Ads** – to improve search visibility and attract more customers
- 🛠️ **Admin support & maintenance** – 1 year of included maintenance and updates

## 🏗️ Tech Stack

This project uses the following technologies:

- **Frontend**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Context API
- **Integrations**: WhatsApp API
- **Deployment**: Ready for Vercel, Netlify, or similar platforms

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/belacstar/ching-ling-restaurant.git
   cd ching-ling-restaurant
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application.

5. **Build for production**
   ```bash
   npm run build
   ```
